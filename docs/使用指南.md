# 模联文件管理系统 · 使用指南

本指南面向**代表（Delegate）**与**学术组（Academic）**用户，介绍系统的日常使用方法。

---

## 一、系统简介

系统提供四大空间与三项危机联动功能，用于会议期间的文件流转、磋商与危机管理：

| 空间/功能 | 用途 | 代表权限 | 学术组权限 |
|------|------|---------|-----------|
| **内阁空间** | 本内阁内部工作区，严格隔离 | 上传 / 查看 / 下载 / 删除（仅本内阁） | 不可见 |
| **公共空间** | 官方发布区（指导文件、决议公布） | 只读 / 下载 | 上传 / 下载 / 删除 |
| **会议空间** | 向大会提交文件，学术组审核 | 提交 / 查看自己的提交 | 查看全部 / 一键复制 / 删除 |
| **磋商空间** | 与其他内阁"拉群"式双边/多边磋商（文字 + 文件） | 拉群 / 发文字 / 发文件（≥2 内阁） | 查看全部群聊 / 发文字 / 发文件 |
| **局势时间线** | 学术组发布局势更新与新闻 | 只读 / 筛选 / 下载附件 | 发布 / 删除 |
| **指令提交** | 代表提交指令，学术组审核答复 | 提交 / 查看本内阁指令 / 删除等待中的指令 | 查看全部 / 筛选 / 审核 / 答复 |
| **不对称消息** | 学术组与单个内阁的一对一私密通道 | 本内阁通道（文字 + 文件） | 全部内阁通道（文字 + 文件） |

## 二、登录与注册

### 2.1 注册账号

1. 打开系统首页，点击「立即注册」。
2. 填写**用户名**（登录用）与**密码**（至少 6 位）。
3. 选择**身份**：
   - **代表**：将归属某个国家/代表团（内阁）
   - **学术组**：将归属主席团或危机团队
4. 在「所属组织」下拉框中**选择管理员已开设的组织**（下拉列表为空时，请联系管理员开设后再注册）。
5. 点击「注册」，成功后回到登录页。

> 注意：注册时只能选择管理员开设的组织，不能自行创建。

### 2.2 登录

输入用户名与密码即可进入系统。登录后会自动进入你所属角色的默认空间。

### 2.3 忘记密码

密码不提供自助找回。请联系系统管理员重置密码。

## 三、内阁空间（代表专属）

> 学术组无法进入该空间。

- **上传文件**：点击「选择文件」，选定后**自动上传**（无需二次确认）。上传成功有提示。
- **查看文件**：列表展示本内阁的所有文件（仅本内阁成员可见，数据严格隔离）。
- **下载文件**：点击文件行右侧「下载」。
- **删除文件**：点击「删除」，确认后移除（仅本内阁成员可操作本内阁文件）。

建议将内部工作文件（草案草稿、立场文件初稿等）存放于此。

---

## 四、公共空间

官方发布区，全员可见。

- **代表**：浏览文件列表并下载，不可上传/删除。
- **学术组**：
  - 上传官方文件（指导文件、决议公布等）
  - 删除文件
  - 通过「会议空间」的一键复制功能发布文件到此（来源会标注「会议空间复制」）

---

## 五、会议空间

### 5.1 代表：提交文件

- 点击右上角「提交文件」，选择文件后**自动上传**。
- 默认查看「我的提交」；**提交后不可修改或删除**，如需更换请重新提交或联系学术组处理。

### 5.2 学术组：审核与管理

- 「全部提交」标签页查看所有代表的提交，列表中会显示**上传者及其所属内阁**，便于识别来源。
- **一键复制**：点击「一键复制到公共空间」，将会议文件发布到公共空间（用于公布通过的决议等）。
- **删除**：移除不合规的提交。

---

## 六、磋商空间（IM 聊天）

群组式文件磋商界面。代表可创建群聊，学术组可查看全部群聊并参与；管理员可经侧边栏「群聊管理」入口进入，权限与学术组相同。

### 6.1 发起磋商（拉群）

磋商以**群组**形式进行，一个群可包含 2 个或更多内阁：

1. 点击右侧「新建群」。
2. 在列表中选择参与磋商的内阁（**至少 2 个**，列表自动排除自己所在内阁）。
3. 可填写**群名**；留空则自动以成员名命名（如"法国 · 英国"）。
4. 确认后进入该群。同一组内阁重复拉群会复用已有群。

> 群名创建后可通过群聊顶部的「改群名」随时修改。

### 6.2 发送文字消息

- 在底部输入框输入文字，按 **Enter** 发送，**Shift + Enter** 换行。
- 支持中文输入法：选词时按回车不会误发送，确认候选词后再按回车即可发出。
- 文字消息同样以气泡展示：自己的靠右（蓝色），其他人的靠左（白色）。

### 6.3 发送文件

- 点击底部「发送文件」，选择文件后自动发送到群内，所有成员可见。
- 文件消息显示为文件卡片，点击即可**下载**。
- 发送文件时可同时在输入框填写**附言**，文件与说明会一并发送。

### 6.4 粘贴即上传

- **图片**：在聊天**输入框聚焦**时直接 **Ctrl/⌘ + V** 粘贴截图或复制的图片，系统会弹出预览确认框——确认缩略图无误后点「发送」，图片即上传到当前群聊。
- **文件**：复制文件后同样粘贴即可，预览框会显示文件名与大小；非图片文件显示为文件卡片图标。
- 粘贴后若想附带说明，可在预览框的「附言」输入框填写，随文件一并发送。
- 取消或关闭预览框即放弃上传，不会产生任何消息。

### 6.5 图片预览

- 群内收到的图片消息会直接**内联展示缩略图**，无需下载即可查看。
- 点击缩略图可**放大预览**，支持缩放、旋转等操作（Element Plus 查看器）。

### 6.6 发送者显示

- 每条消息上方显示**发送者用户名及其所属内阁**，格式如「张三（法国）」，便于识别具体是哪位代表发送。
- 学术组发送的消息显示为「用户名（学术）」，并保留"学术"标记。
- 自己的消息靠右（蓝色），其他人的靠左（白色）。

### 6.7 未读提示

- 左侧群列表中，有未读消息的群会显示**红色数字徽标**。
- 打开群查看消息后，未读自动清零。
- 系统每 3 秒自动刷新消息与未读状态，无需手动刷新页面。

### 6.8 学术组与管理员的参与

学术组（主席团/危机团队）可以**查看全部群聊**并在群内发送文字消息与文件（身份显示为其所属组织），用于指导磋商进程。

管理员拥有与学术组相同的群聊权限：经侧边栏「**群聊管理**」入口查看全部群聊、发送文字消息与文件、**解散群聊**（头部红色按钮）。双方均**不能创建群聊**。

> 代表只能**退出**群聊（头部「退出群聊」按钮），退出不影响群内文件；**解散群聊**仅限学术组与管理员，以便审议剩余文件。

## 七、会期管理（学术组专属）

会期是全局状态，作为局势时间线与指令提交的归属依据；切换后全员即时生效。

- 通过侧边栏「**会期管理**」进入。
- **切换方式**（三种，选择即保存、无需额外确认）：
  - 下拉选择已有的会期
  - 点击「**下一个会期**」自动按最新编号 +1 创建并切换
  - 手动输入编号（名称选填，不填则仅显示编号）创建并切换
- 列表展示全部会期及其编号、名称、创建时间，当前会期带标记。
- **代表**在页面顶部只读看到「当前会期：第X会期（名称）」，无任何管理入口。

## 八、局势时间线

学术组发布局势更新与新闻，代表实时接收。所有条目混排、按发布时间倒序展示。

### 8.1 代表：查看

- 通过侧边栏「**局势时间线**」进入。
- 条目格式：
  - 局势更新：`[局势更新][1.1] 内容`
  - 新闻：`[新闻][1.2][塔斯社] 内容`（编号 = 会期.序号，局势更新与新闻**各自独立编号**，删除不回填）
- 顶部可按**会期**与**类型**（局势更新/新闻）组合筛选。
- 图片附件直接**内联展示**，点击可放大；其他附件点击下载（中文文件名不乱码）。
- 新条目通过 SSE 实时推送并弹出**浏览器通知**，无需刷新页面。

### 8.2 学术组：发布与删除

- 点击「**发布**」，选择类型（局势更新/新闻，必选）；类型为「新闻」时显示可选的**新闻来源**（如"塔斯社"）。
- **内容与附件至少填写一项**；附件任意类型（图片内联展示，其他文件可下载）。
- 发布后自动编号，条目不支持编辑——误操作请**删除后重新发布**（删除不回填编号）。

## 九、指令提交

代表向学术组提交指令，学术组审核并给出可选答复。

### 9.1 代表：提交指令

- 通过侧边栏「**指令提交**」进入。
- 点击「提交指令」：选择**指令类型**（必选）、填写**内容**（必填）、可附**附件**（图片内联预览/粘贴即上传）。
- 指令自动归属**当前会期**，编号格式 `[内阁名][指令类型][会期.序号]`（序号按本内阁、本会期、本类型独立递增，删除不回填）。
- 列表仅显示**本内阁**的指令，状态一目了然：
  - **等待**（黄色）：可删除（确认后移除，编号不回填）
  - **接受**（绿色）：显示学术组的答复（文本 + 图片/附件）
  - **驳回**（红色）：显示学术组的答复
- 审核结果通过 SSE 实时推送并弹**浏览器通知**。

### 9.2 学术组：审核与答复

- 通过侧边栏「**指令列表**」进入，可看到**所有内阁**的指令。
- 顶部可按**会期 / 指令类型 / 内阁**组合筛选。
- 点击「审核」：**接受 / 驳回二选一**（操作后**不可逆**）；可附**答复**（文本 + 图片/附件），接受与驳回均可填或不填。
- 新指令到达时实时推送并弹**浏览器通知**。

### 9.3 管理员：指令类型管理

- 通过侧边栏「**指令类型管理**」进入。
- 系统预设 6 种类型（外交、内政、情报、舆情、军事、经济指令），管理员可**新增自定义类型**，也可**删除任意类型**（含预设）。
- 删除类型后，已提交的指令**保留该类型名称**（快照），不受影响。

## 十、不对称消息

学术组与单个内阁之间的一对一**私密**沟通通道，功能与磋商空间一致；管理员完全隐身、不可见。

- **代表**：侧边栏「不对称消息」直接进入本内阁与学术组的对话（无需选择）；**同内阁成员共享同一对话**，彼此可见。
- **学术组**：左侧列出全部内阁，点击进入对应对话（每个内阁一个独立频道），可切换查看。
- 支持：
  - 文字消息（**Enter 发送 / Shift+Enter 换行**，中文输入法友好）
  - 图片**内联预览**（点击放大）
  - **粘贴即上传**（输入框聚焦时 Ctrl/⌘ + V）
  - 附件发送与下载（中文文件名不乱码）
- 新消息实时推送并弹**浏览器通知**：学术组收到内阁消息时通知，内阁收到学术组消息时通知。

## 十一、常见问题（FAQ）

**Q1：注册时「所属组织」下拉是空的？**
说明管理员还未开设任何组织（或你选择的身份下没有对应类型——代表只能选「内阁」类型，学术组只能选「主席团/危机团队」）。请联系管理员开设。

**Q2：上传文件失败，提示文件过大？**
单个文件上限为 **50MB**。请压缩或拆分后再上传。

**Q3：登录后提示 401 / 被踢回登录页？**
登录状态已过期，重新登录即可。

**Q4：下载的文件名乱码或显示异常？**
系统已按规范处理中文文件名，若仍有问题，请记录文件名并反馈给管理员。

**Q5：我提交的会议文件能自己删除吗？**
不能。会议空间提交后不可修改/删除，由学术组统一管理。

**Q6：能在磋商空间聊天打字吗？**
能。磋商空间支持**文字消息**（Enter 发送 / Shift+Enter 换行）与文件往来两种方式，发送文件时还可附带文字附言。

**Q7：图片能直接看吗？**
能。群内图片消息会内联显示缩略图，点击即可放大预览，无需下载。

**Q8：粘贴图片/文件直接上传是什么？**
在聊天窗口输入框聚焦时，直接 Ctrl/⌘ + V 粘贴截图或复制的文件，系统会弹出预览确认框，确认后发送到当前群聊。

**Q9：学术组能看到磋商空间吗？**
可以。学术组可查看**全部群聊**并在群内发送文字消息与文件（身份显示为其所属组织），但不能创建群聊。管理员同样可以（经侧边栏「群聊管理」入口），并有权**解散群聊**。

**Q10：时间线/指令编号为什么有跳号（如 1.1、1.3）？**
编号自动生成且**删除不回填**。中间条目被删除后，后续条目继续按最新编号递增，这是设计行为。

**Q11：指令审核后还能修改吗？**
不能。接受/驳回操作后**不可逆**。审核前请确认；如需调整，可让代表重新提交新指令。

**Q12：不对称消息和磋商空间有什么区别？**
不对称消息是学术组与**单个内阁**的一对一**私密**通道，只有对话双方可见（同内阁成员共享）；磋商空间是多内阁群聊。两者操作方式一致。

**Q13：学术组为什么看不到「会期管理」？**
会期管理入口仅学术组侧边栏可见；管理员不参与会期管理。

## 十二、账号与安全

- 请勿将账号密码告知他人；不同代表团的文件严格隔离，借用账号会导致数据泄露。
- 如需修改密码，请联系系统管理员。
- 系统首次部署会自动创建管理员账号（admin），管理员可管理账户与组织；如需开通新组织或新账号，请联系管理员。
